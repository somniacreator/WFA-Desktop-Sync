# WFA Desktop Sync

Программа для Windows: один раз входите через Telegram, дальше данные аддона **WFA Armory Exporter** сами попадают в **WFA Mini App** ([wfarmory.ru](https://wfarmory.ru/), Telegram @WoWForeverRUBot).

## Скачать
- **С сайта (работает без VPN):** [WFA-Desktop-Sync.exe](https://wfarmory.ru/api/desktop/v1/app/file/latest/WFA-Desktop-Sync.exe)
- **С GitHub:** [последний релиз](https://github.com/somniacreator/WFA-Desktop-Sync/releases/latest)
- Кнопка «WFA Sync» на главной странице приложения

Если GitHub не открывается у вас без VPN, берите файл с сайта.

## Установка
1. Скачайте `WFA-Desktop-Sync.exe` и запустите. Программа установится в `%LOCALAPPDATA%\Programs\WFA Desktop Sync` (права администратора не нужны), добавит ярлык и значок в трей.
2. Нажмите **«Войти через Telegram»** и подтвердите подключение в боте.
3. Играйте. WoW записывает файл аддона при **выходе из игры или `/reload`**, после этого данные передаются сами.

Нужен аддон [WFA Armory Exporter](https://www.curseforge.com/wow/addons/wfa-armory-exporter). Если его нет, программа предложит установить встроенную копию.

## Обновления
Программа сама проверяет стабильные релизы (через wfarmory.ru, GitHub как запасной путь), проверяет SHA-256 и ставит новую версию при следующем запуске. В окне есть кнопка «Проверить обновления» и «Перезапустить и обновить».

## Закрытие и выход
Закрытие окна не останавливает программу, она работает в фоне (значок в трее). Полный выход: «Выйти из программы» в окне или «Выход» в меню значка.

## Безопасность
- Читает только файл `WFA_Armory_Exporter.lua` игры, диски и документы не сканирует.
- Копии и очередь хранятся на вашем компьютере; снимок считается отправленным после подтверждения сервера.
- SmartScreen может предупредить, что файл не подписан: «Подробнее» → «Выполнить в любом случае». Контрольная сумма лежит рядом с файлом (`.sha256`).
- Подробности: `PRIVACY_RU.md` в релизе. Вопросы и удаление данных: @WFAsupport.

Не является официальным продуктом Blizzard или Telegram.
